How to read this: Four KRAs are calculated automatically from the sales sheet — Sales Achievement (60%), Conversion & Productivity (15%), Team Expansion (10%) and Attrition & Retention (5%). The remaining two — Leadership (5%) and Reporting Discipline (5%) — are qualitative. Manager KRA Master Sheet: Leadership and Reporting Discipline scores (and optional sub-metrics — conversion-funnel %, headcount, avoidable attrition) are pulled automatically from a second Google Sheet, the "Manager KRA Master Sheet" — fill scores in there and they show up here pre-filled (still editable per session). That same sheet is where you add managers from other departments: any manager/month row you add there appears as its own card here, scored on Leadership/Reporting/Attrition immediately and on Sales/Productivity/Expansion once you give them Target & Achieved figures via "✏️ Edit raw data" (until then those three KRAs show "N/A" and the score is reweighted over what does apply). Live data: this page pulls Target/Achieved/BDE/Cost from the Sales Data Sheet and Leadership/Reporting/sub-metrics from the Master Sheet each time it's opened — both sheets need "Anyone with the link" (Viewer) access turned on for this to work from a browser with no server in between. Click "🔄 Refresh from Sheet" any time to re-pull either. New months are automatic: add a new tab to the Sales Data Sheet named like the existing ones (e.g. "Nov'26") and it's picked up on the next load or Refresh — no setup needed. Only tabs from July 2026 onward count as dashboard months (earlier tabs in that sheet predate this appraisal and are ignored). The Master Sheet works the same way already — just add rows with that month's label. Everything here is also editable: open "✏️ Edit raw data" on any manager card to correct a figure by hand — the % achieved, ROI, KRA scores, charts and totals all recalculate instantly. Note: hand-edits and any Leadership/Reporting score you change here (overriding the Master Sheet) only last for this browser tab/session — a "🔄 Refresh" or closing the tab discards them, so make lasting changes in the Master Sheet itself. Use "↺ Reset all data" to discard edits and go back to the last fetched (or saved) figures.

KRA Weightage Framework (reference)
From the "Sales Manager KRA & Weightage Structure" document — solid bars are auto-calculated in this dashboard, hatched bars need manual HR input
Methodology. Sales Achievement score = % of target achieved (capped at 100). Productivity score = the manager's Average-Revenue-per-BDE relative to the best performer that month. Team Expansion score = whether BDE headcount held or grew vs. the prior month in scope (100 if maintained/grew). Attrition score = 100 − attrition % (from the Sales Data Sheet if tracked there, else from the Master Sheet's Avoidable Attrition column, else assumed 0). Leadership and Reporting Discipline come from the Manager KRA Master Sheet (1–5 scale), editable per session from any manager card. A manager with no Target/Achieved on file yet (e.g. a newly added other-department manager) shows Sales/Productivity/Expansion as N/A and their Final Score is reweighted over Attrition + Leadership + Reporting only, until Target/Achieved figures are added.
Live fetch, the Master Sheet & known data gaps. On load (and on "Refresh from Sheet"), this page first reads the Sales Data Sheet's own tab list — see discoverSheetTabs() near SHEET_ID in the script — to rebuild MONTH_TABS automatically from whatever month tabs actually exist there (named like "Sep'26"; only July 2026 onward counts — see MONTH_START_CUTOFF), then pulls each month's data plus the Manager KRA Master Sheet — see MASTER_SHEET_ID/MASTER_GID — via their published CSV feeds, and re-derives every field through the same formulas as the manual edit boxes. Both sheets need "Anyone with the link" (Viewer) access turned on for a browser to read them with no server in between. The Sales Data Sheet's column layout differs slightly month to month (e.g. July adds a "DRR" column, August adds "Attrition %" and "Avg. per subscription cost", some months split into 1st/2nd fortnight tables) — the parser matches columns by name and sums fortnight tables automatically, but a month with a genuinely new layout may need a quick check. The Master Sheet is matched by its "Month" column text against each discovered tab's label, so a month's tab must exist in the Sales Data Sheet before its Master Sheet rows are picked up. Conversion-funnel metrics (lead→demo→payment) and headcount/attrition sub-metrics from the KRA document live in the Master Sheet and show as reference figures on each manager's card — they're not yet folded into the weighted score beyond feeding Attrition, since the funnel stages don't map to a single 0–100 KRA score on their own; extend computeAllScores if you want to add that. If either fetch fails (e.g. link-sharing isn't turned on yet, or the tab-list page's markup changes), the dashboard falls back to the last known month list and figures it successfully loaded.
